ANP — ÍCONE CORRIGIDO (FUNDO VERDE ATÉ AOS QUATRO CANTOS)

Todos os ícones têm agora fundo verde OPACO, sem transparência e sem cantos brancos.

1. Extrai este ZIP.
2. Em https://github.com/lamancha-dev/anp clica Add file > Upload files.
3. Arrasta os 8 ficheiros da pasta extraída (não o ZIP).
4. Clica Commit changes.
5. Aguarda a publicação no GitHub Pages.
6. No Android, remove o atalho/app ANP antigo se existir.
7. Abre https://lamancha-dev.github.io/anp/ no Chrome e instala.

Se o Chrome continuar a mostrar o ícone antigo, limpa os dados do site github.io no Chrome antes de tentar novamente.
